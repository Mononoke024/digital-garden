### For pushing content to live github page
After updating content in Obsidian:
to view page on local server, use
`npx quartz build --serve`

to sync content
`npx quartz sync`
can also use `git push` 

to check there are no new commits left behind
`npx quartz sync --no-pull`

if the github url sync disappears *and goes back to github.com*
use `git remote set-url origin https://github.com/Mononoke024/digital-garden.git`
